Help & guides

How to get good answers, and what each part of DocAssist does.

{% icon "sparkles" 18 %} Getting good answers

  • Be specific. Name the program, form, year or person you mean.
  • Ask one thing at a time. Split long questions into steps.
  • Follow up naturally. The assistant remembers the conversation, so "what about the deadline?" works.
  • Check the sources. Each answer lists the file and page it came from.
✕ "Tell me about it"
✓ "What support does WhiteBox give innovators for patents?"

{% icon "shield" 18 %} What the assistant can and can't do

  • It answers only from your organization's documents, not from the internet.
  • If the documents don't cover something, it says so instead of guessing.
  • Documents from other organizations are never searched or shown.
  • It can still make mistakes. Use 👎 to flag a wrong answer so an admin can fix it.

{% icon "bookmark" 18 %} Rating and saving answers

  • 👍 / 👎 under each answer tells admins what works. Add a short note when you click 👎.
  • Save keeps an answer in Saved answers, visible only to you.
  • Copy copies the answer text to paste elsewhere.

{% icon "users" 18 %} Roles

  • Member: chat, browse documents, save answers.
  • Admin: also uploads documents and sees analytics, feedback, knowledge gaps, API keys, members and settings.
  • Owner: everything an admin can do, plus making other people owners.

Items with a {% icon "lock" 12 %} in the menu are for admins. Ask an owner or admin if you need access.

{% icon "file" 18 %} For admins: managing documents

  1. Upload PDF, TXT or Markdown files on Documents. Text-based PDFs work best; scanned images can't be read yet.
  2. Wait for the status to show Ready, usually a few seconds per document.
  3. Check Knowledge gaps and Feedback each week to see what's missing.
  4. To update a document, delete the old version and upload the new one.

{% icon "key" 18 %} For admins: connecting apps

Create a key under API keys, then send questions from your website or app:

POST /api/v1/chat
Authorization: Bearer sk_your_key
{"question": "What is WhiteBox?"}

Answers come from this organization's documents only.
