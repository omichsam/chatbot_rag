{% icon "help" 16 %} How the audit log works
  • Every console action writes one entry automatically; entries can't be edited or deleted from the app.
  • Changes recorded as "label: old → new" are shown as before and after.
  • Failed sign-ins, sign-in pauses and two-factor events appear under Security.
  • The organization's name is stored with each entry, so it still reads correctly after an organization is deleted. Export to CSV for reviews or compliance.
