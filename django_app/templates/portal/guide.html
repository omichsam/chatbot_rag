Console guide

What the Platform Console is for, who can use which part, and how each part works.

{% icon "shield" 18 %} The console is not a workspace

Organizations work in their workspace (chat, documents, settings). The Platform Console is where the platform team operates every organization at once. It has its own dark sidebar and a status bar showing the environment, maintenance and AI providers, so it's always clear you're acting on everyone. Use Exit to workspace to go back; in the workspace, the Platform Console link brings you here.

Platform team (console)→Organizations→Owners & admins (workspace)→Members

Give someone a role on Users (Console column). Superadmin status gives the owner role and is changed only by typing the username to confirm.

{% icon "dashboard" 18 %} Dashboard

  • Questions, active organizations, active people and answer reliability for 7, 30 or 90 days, each compared with the period before.
  • AI providers: who wrote the answers, their speed, failures and last error; how many answers were quoted or reused.
  • Every organization's usage, what needs attention, system health and recent console actions. Usage CSV exports usage per organization.

{% icon "building" 18 %} Organizations and plans

  • Plans package limits (questions per month, documents, members, cloud AI allowed) and apply in one click.
  • Suspend needs a reason. Schedule deletion takes it offline and deletes it after 30 days unless cancelled; Delete now skips the wait. Both ask you to type the name.
  • Export data downloads a zip with everything the organization owns, including its files.
  • View as this organization opens its workspace read-only (support mode), with a banner and an audit-log entry.

{% icon "shield" 18 %} Security centre

  • Everyone with console access, their role and whether two-factor sign-in is on.
  • Require two-factor sign-in for the console (set yours up first).
  • Failed sign-ins and sign-in pauses for the last 30 days.
  • Every API key across organizations, flagged when never used, unused for 90 days, or older than 180 days.

{% icon "history" 18 %} Audit log

  • Filter by action, person, organization, text and dates; page through 25 at a time; export CSV.
  • Changes recorded as "label: old → new" show as before and after.

{% icon "search" 18 %} Search

  • Ctrl K searches organizations, users and API keys across the whole platform, and jumps to any console page you can use.

{% icon "lock" 18 %} Good practice

  • Turn on two-factor sign-in for everyone with console access.
  • Give people the narrowest role that does the job; keep owners to one or two named people.
  • Prefer suspend or scheduled deletion over deleting now. Export first if the data might be needed.
  • Use support mode for support; it's recorded. Check the dashboard and security centre weekly.
